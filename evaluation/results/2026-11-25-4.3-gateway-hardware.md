**25 November 2026 · Card 4.3 · Three synthetic HR passages, no hold-out data**

The development PC reported Intel Iris Xe integrated graphics and 1 GiB of adapter memory through Windows CIM. Ollama listed one installed model, `llama3.2:3b` (2.0 GB, Q4_K_M). The S7 optional candidate `gemma4:e4b` was absent.

**Method.** Inspect the adapter with `Get-CimInstance Win32_VideoController`, then run `ollama list` and `ollama show llama3.2:3b`. Use the optional LangChain Ollama integration with a fresh in-memory gateway, one candidate and no fallback. Ask “Write a one-sentence header for this synthetic HR policy: staff may carry N unused leave days into January.” Use N = 5, 3 and 7, prompt version `feasibility@1`, and an output cap of 40 tokens. Each input was 48 tokens. The hosted observations came from `uv run --env-file .env ekb demo gateway`, which uses a different passage and output cap.

**Decision.** Keep the working free-tier chain as the POC default. It can serve the demo without a local model installation. Keep Ollama available for offline work. This machine can run the installed 3B model.

**Limits.** The small sample establishes operational feasibility. The two workloads and models differ, so these timings do not rank providers or establish p95 latency, a confidence interval or answer quality. Revisit the choice when the intended local model is available, using the same prompts and quality gates on both routes.
