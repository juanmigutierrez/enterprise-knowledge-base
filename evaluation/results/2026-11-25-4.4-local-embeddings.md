# S10 local embedding feasibility

**25 November 2026 · Card 4.4 · Synthetic HR data**

The local POC uses the gateway’s `model` option with `ollama:bge-m3` and 1,024 dimensions. The demo compares an English annual-leave question with Italian and Spanish translations and two unrelated English sentences. Scores below are the cosine similarities printed by the demo, rounded to two decimals.

| Option | Italian | Spanish | Expenses | Office hours | Translations in top two | API cost |
|---|---:|---:|---:|---:|---:|---:|
| Ollama bge-m3 | 0.91 | 0.95 | 0.56 | 0.40 | 2 of 2 | $0 |
| Demo hash model | 0.02 | 0.04 | 0.03 | 0.00 | 1 of 2 | $0 |

**Method.** Run `ollama pull bge-m3`, set `OLLAMA_URL` to `http://127.0.0.1:11434`, and run `uv run --extra ollama ekb demo t7`. Use `uv run ekb demo t7 --fake` for the deterministic control. The demo starts with an empty in-memory vector cache and uses no hold-out questions.

**Lifecycle observations.** The local model embedded all 48 chunks across 12 pages. Editing one sentence sent one chunk and reused three. An ACL-only event sent zero chunks. Deleting a page removed four cached vectors. All 44 surviving chunks lacked an ACL and stayed unpublished.

**Decision.** Keep bge-m3 as the local POC default. It ran on this machine and ranked both translations ahead of the unrelated sentences. The S18 golden-set comparison will measure retrieval quality across models. This five-sentence run provides no corpus-level recall or latency estimate.
